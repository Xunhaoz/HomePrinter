# HomePrinter 前端 User Stories

> 範圍：shadcn/ui 風格的網頁前端，主要裝置是 iPhone Safari，也要支援桌機（RWD）。服務會暴露在外網，用一組通行碼登入。
> 依據：`README.md`、`backend/src/homeprinter/app.py`（以及 `jobs.py`、`scans.py`、`scanner.py`、`schedules.py`、`printer.py`、`config.py`）。
> 優先序用 MoSCoW：**M** = Must（MVP 必備）、**S** = Should、**C** = Could、**W** = Won't（這次不做）。

---

## 0. 給前端的關鍵限制（先讀這段）

| 限制 | 對 UI 的影響 |
|---|---|
| 印表機一次只送一份 PWG，PDF 的份數是靠在文件裡重複頁面 | PDF 的 `pages_total` = 頁數 × 份數（雙面時可能補空白背面）；進度條要用 `pages_done / pages_total`，不要自己算 |
| 雙面只支援 PDF（`sides`），照片一律單面 | 檔案是圖片時，隱藏或停用「雙面」選項；`pages` 頁碼範圍也只對 PDF 有效 |
| 列印工作存在記憶體，服務重啟後就消失，而且最多保留 100 筆已結束的工作 | `GET /jobs/{id}` 可能回 404；排程的 `last_job` 連結也可能失效。UI 要把它當成「紀錄已清除」處理，不是錯誤 |
| 印表機忙碌或連不上時，工作會留在 `queued` 或 `printing`，每 5 秒重試一次，最多 10 分鐘，之後才變 `failed` | 工作卡住時，要搭配 `GET /printer` 告訴使用者原因（請看 C-5） |
| 同時只能有一個掃描，不排隊；掃描中再送會回 409 | 掃描按鈕要依 `GET /scanner` 的 `busy` 停用；409 要用友善訊息提示 |
| 送紙器（ADF）只能單面；沒放紙會回 409 | 依 `adf_state` 提示「請先放紙」 |
| 送紙器多頁掃描選 JPEG 時會回傳 zip | iPhone 處理 zip 不方便，送紙器預設用 PDF，選 JPEG 時要提醒 |
| 掃描約 15–30 秒（100–300 dpi），600/1200 dpi 更久 | 要有明確的等待狀態，並且可以離開頁面再回來看 |
| 掃描檔保留 `SCAN_RETENTION_DAYS`（預設 7 天）後自動刪除 | 列表要顯示 `expires_at` 剩幾天 |
| 一次性排程跑過之後會自動停用，不能再恢復（409） | 已結束的一次性排程不要顯示「恢復」 |
| 排程的 `last_status` 只有 `submitted`、`failed`、`missed`。`submitted` 只代表工作已送出，不代表已印好 | 真正的結果要再查 `last_job` |
| `config.py` 已經有 `ACCESS_CODE`（不分大小寫）、`SESSION_DAYS`（預設 30）、`ROOT_PATH`，但 `app.py` 還沒有任何驗證 | 登入 API 要後端補上（請看第 4 節） |

## 1. Personas

### P1 阿翔（主要使用者，也是管理者）
- 30 多歲，自己架了這台服務，iPhone 是主要裝置，偶爾用桌機。
- 常做的事：用 4×6 相紙印 iPhone 拍的照片（HEIC），印 A4 PDF（帳單、合約，常用黑白雙面），設定每週一早上印一張噴頭檢查頁，避免 EcoTank 的墨水乾掉，也會看墨水量。
- 需求：參數要能調整，但常用組合要一鍵完成；想知道「到底印出來了沒」。
- 痛點：每次都要選紙張、品質、縮放，很麻煩；iPhone 的照片是 HEIC 格式。

### P2 林媽媽／國中生小妤（偶爾使用的家人）
- 一個月用幾次：掃孩子的作業或考卷傳給老師，掃身分證或健保卡影本，印學校通知。
- 對 3C 不熟，看到 dpi、PWG、cron 這些詞會卡住。
- 需求：大按鈕、預設值就能用、掃完可以直接「分享到 LINE」或存到「檔案」。
- 痛點：記不住通行碼（要能長時間保持登入）；按了掃描卻跳出看不懂的錯誤，例如「scanner is busy」。

### P3 阿翔在外面（遠端送印和排程的情境）
- 在公司或通勤時用 4G/5G 開網頁：先把文件印好讓家人拿，或排程「明天 7:30 印出今天的會議資料」。
- 需求：在家以外的網路也能安全使用；上傳大檔案時看得到進度；看不到印表機，所以要知道「有沒有紙、有沒有開機、印成功了沒」。
- 痛點：印表機關機時工作會默默卡住 10 分鐘；行動網路會斷線。

## 2. 建議的資訊架構（給 RWD 版面參考）

- 手機：底部有 4 個分頁：**首頁**（印表機狀態、墨水量、快速動作、最近工作）、**列印**、**掃描**（含掃描檔列表）、**排程**。設定和登出放在首頁右上角的選單。
- 桌機（≥ 1024px）：左側導覽列加主內容。列印頁可以左邊放表單、右邊放工作列表。
- 共用元件（shadcn/ui）：`Card`、`Button`、`Select`、`ToggleGroup`（單雙面、色彩）、`Sheet`（手機上的進階選項）、`Dialog`/`AlertDialog`（取消、刪除前確認）、`Progress`、`Badge`（狀態）、`Sonner`（toast）、`Skeleton`。

## 3. User Stories（依 Epic 分組）

格式：**身為…我想要…以便…**。每則都附上驗收條件（AC）和對應的 API。

### Epic A：登入

#### A-1 輸入通行碼進入｜M
身為任何家庭成員，我想要只輸入一組約 6 個英文字母的通行碼就能進入，以便不用申請帳號就能使用，同時陌生人進不來。
- AC
  - Given 我還沒登入，When 我打開任何頁面，Then 會導到登入頁。登入頁只有一個輸入框和一個「進入」按鈕。
  - 輸入框設定 `autocapitalize="none"`、`autocorrect="off"`、`spellcheck="false"`、`autocomplete="current-password"`、`font-size ≥ 16px`（避免 iOS 自動放大），按鍵盤的「前往」就能送出。
  - 通行碼不分大小寫（與 `ACCESS_CODE` 的行為一致）。
  - When 通行碼正確，Then 回到原本要去的頁面，沒有的話就到首頁。
  - When 通行碼錯誤，Then 顯示「通行碼不正確」，輸入框清空並保持焦點；訊息不會透露正確碼的長度或其他提示。
  - When 嘗試太多次（429），Then 顯示「嘗試次數過多，請 N 分鐘後再試」，並停用按鈕直到時間到。
- API：**無，屬於缺口 API-1**（建議 `POST /auth/login`）

#### A-2 保持登入｜M
身為林媽媽，我想要登入一次後很久都不用再輸入，以便下次打開就能直接掃描。
- AC
  - 登入後 `SESSION_DAYS`（預設 30 天）內，重新開 Safari 或從主畫面圖示開啟，都不需要再登入。
  - 通行碼不存在 `localStorage` 或網址中，只靠 HttpOnly cookie。
- API：缺口 API-1

#### A-3 登入過期的處理｜S
身為使用者，我想要登入過期時被帶回登入頁，重新登入後回到原本的頁面，以便不會迷路。
- AC
  - 任何 API 回 401 時，全域攔截並導到 `/login?next=<原路徑>`，不會在各頁各自顯示錯誤。
  - 如果當時表單已經選了檔案，提示「登入已過期，請重新選擇檔案」（`File` 物件沒辦法跨頁保留）。
- API：缺口 API-1

#### A-4 登出｜S
身為阿翔，我想要在借來的電腦上用完後登出，以便別人不能繼續使用。
- AC：選單有「登出」，按下後清掉 session 並回到登入頁；按瀏覽器的上一頁也看不到資料。
- API：缺口 API-1（`POST /auth/logout`）

### Epic B：列印

#### B-1 從 iPhone 選照片列印｜M
身為阿翔，我想要從相簿選一張照片（包括 HEIC）直接印在 4×6 相紙上，以便不用先轉檔。
- AC
  - 檔案選擇器 `accept="image/*,.heic,.heif,application/pdf"`，iOS 會出現「照片圖庫／拍照／選擇檔案」。
  - 選了照片後顯示縮圖（在前端用 `URL.createObjectURL` 產生；HEIC 沒辦法顯示縮圖時，改成顯示檔名和圖示）、檔名和大小。
  - 照片的預設組合是「相片 4×6 滿版」：`media=na_index-4x6_4x6in`、`scaling=fill`、`quality=high`、`color_mode=auto`。
  - 照片不會出現「雙面」和「頁碼範圍」。
  - 按「列印」後收到 202，然後直接切到這個工作的進度畫面（C-1）。
  - 400（格式不支援）時顯示「這個檔案格式無法列印，請改用 PDF、JPEG、PNG 或 HEIC」。413 時顯示「檔案超過 N MB」。
- API：`POST /print`

#### B-2 列印 PDF 文件並調整選項｜M
身為阿翔，我想要印 PDF 時可以選份數、頁碼、黑白／彩色、雙面，以便省紙省墨。
- AC
  - 選項：份數（1–99，用步進器）、紙張、色彩（自動／彩色／黑白）、品質（一般／高）、縮放（符合／填滿／原尺寸）、單雙面（單面／雙面長邊翻／雙面短邊翻）、頁碼範圍（例如 `1-3,5`，空白代表全部）。
  - 雙面選項附一句說明：「長邊翻：一般直式文件；短邊翻：往上翻的月曆式」。
  - 頁碼格式在前端先檢查（只能有數字、`-`、`,`），格式錯誤時不送出，欄位下方顯示錯誤。
  - 預設組合是「文件 A4」：`media=iso_a4_210x297mm`、`scaling=fit`、`sides=one-sided`。
  - 進階選項（品質、縮放）在手機上收在 `Sheet` 或「更多選項」裡，不佔主畫面。
- API：`POST /print`

#### B-3 選項從印表機能力產生，並顯示中文名稱｜M
身為林媽媽，我想要紙張選單顯示「A4」「相片 4×6」而不是 `iso_a4_210x297mm`，以便看得懂。
- AC
  - 進入列印頁時讀取能力資料並快取（同一次使用只讀一次），紙張和其他選項只列印表機支援的值。
  - 前端維護一份對照表（例如 `iso_a4_210x297mm`→A4、`na_index-4x6_4x6in`→相片 4×6、`na_letter_8.5x11in`→Letter、`iso_a6_105x148mm`→A6、`na_5x7_5x7in`→相片 5×7）。不在表上的就顯示原始值。
  - 常用紙張排在最前面（A4、4×6），其餘收在「其他尺寸」。
  - 能力資料讀取失敗（502）時，仍然可以用內建的預設值列印，並顯示「無法連線到印表機」的提示。
- API：`GET /printer/capabilities`

#### B-4 常用設定一鍵套用｜S
身為阿翔，我想要一鍵選「文件黑白雙面」或「相片 4×6」，以便不用每次都調一堆選項。
- AC
  - 內建預設組合：**文件**（A4、自動色彩、單面）、**省墨文件**（A4、黑白、雙面長邊翻）、**相片 4×6**（滿版、高品質）。選了檔案後依類型（PDF 或圖片）自動選一個。
  - 選預設組合後仍可以再微調；組合不適用的選項（例如圖片的雙面）會自動停用。
  - 上次用過的組合存在 `localStorage`（只是方便用，讀寫都要包在 try/catch 裡）。
- API：只有前端，不需要 API

#### B-5 一次印多張照片｜S
身為阿翔，我想要一次選好幾張照片送印，以便旅行回來可以一起印。
- AC
  - 檔案選擇器加上 `multiple`。送出時依序呼叫多次 `POST /print`（一次一個檔，不要同時送），每個檔案各有自己的工作和進度。
  - 其中一張失敗不會影響其他張，最後彙整「成功 N 張／失敗 M 張」。
- API：`POST /print`（重複呼叫）

#### B-6 上傳進度（遠端、行動網路）｜S
身為在外面的阿翔，我想要看到上傳進度，以便知道大的 PDF 還在傳，不是當掉了。
- AC
  - 用 `XMLHttpRequest` 的 `upload.onprogress` 顯示上傳百分比（`fetch` 沒有上傳進度）。
  - 上傳完成到收到 202 之前，顯示「處理中…」。
  - 網路中斷時顯示「上傳失敗，請重試」，而且保留已選的檔案和選項，可以直接重送。
- API：`POST /print`

#### B-7 送印前檢查（試印）｜C
身為阿翔，我想要先確認檔案和選項印表機能接受，以便遠端送印時不浪費紙。
- AC：進階選項有「只檢查不列印」（`dry_run=true`）；工作完成後顯示「檢查通過，總共 N 頁」。
- API：`POST /print` 帶 `dry_run=true`

### Epic C：列印工作追蹤

#### C-1 看到列印進度｜M
身為阿翔，我想要送出後看到「轉換中→列印中 3/8 頁→完成」，以便知道什麼時候可以去拿。
- AC
  - 每 2 秒輪詢一次，直到狀態變成 `completed`、`failed` 或 `canceled`。頁面在背景時（`visibilitychange`）暫停，回到前景時立刻重新抓一次。
  - 狀態對照：`queued` 排隊中、`rendering` 轉換中、`printing` 列印中、`completed` 已完成、`failed` 失敗、`canceled` 已取消，用不同顏色的 `Badge` 表示。
  - `printing` 時顯示 `Progress`（`pages_done / pages_total`）和「第 X / Y 頁」。
  - `dry_run` 的工作要標示「試印（未出紙）」。
  - 404 時顯示「找不到這個工作（服務可能重新啟動過）」，並且停止輪詢。
- API：`GET /jobs/{id}`

#### C-2 取消列印｜M
身為阿翔，我想要取消送錯的工作，以便不浪費紙和墨水。
- AC
  - 只有 `queued`、`rendering`、`printing` 狀態會顯示「取消」，按下後用 `AlertDialog` 確認。
  - 取消後立刻更新狀態。`printing` 的工作可能還會再印出一兩頁，所以要提示「已送出的頁面可能仍會印出」。
- API：`DELETE /jobs/{id}`

#### C-3 最近的列印工作｜S
身為林媽媽，我想要看到最近印了什麼和結果，以便確認剛剛那份有沒有印。
- AC
  - 列表依時間由新到舊排列，顯示檔名、狀態、頁數、時間（相對時間，例如「3 分鐘前」）。
  - 有進行中的工作時，列表每 3 秒自動更新；沒有的話就不輪詢。
  - 空的時候顯示：「目前沒有列印紀錄。服務重新啟動後，紀錄會清除。」
- API：`GET /jobs`

#### C-4 看得懂失敗原因｜M
身為林媽媽，我想要列印失敗時看到中文原因和下一步，以便自己處理或知道要找誰。
- AC
  - `failed` 時顯示前端整理過的訊息（請看第 5.3 節），原始的 `error` 收在「詳細資訊」裡。
  - 提供「重新列印」：如果這次使用中還留著原本的 `File`，就直接重送；沒有的話就回到列印頁，並帶入原本的選項（伺服器在工作結束後會清掉檔案內容）。
- API：`GET /jobs/{id}`、`POST /print`

#### C-5 印表機沒回應時，工作不會默默卡住｜S
身為在外面的阿翔，我想要在印表機關機或沒紙時知道工作在等什麼，以便請家人去處理，或是先取消。
- AC
  - 工作停在 `queued` 或 `printing` 超過 20 秒，而且 `pages_done` 沒有增加時，額外呼叫一次 `GET /printer`：
    - 502 → 顯示「無法連線到印表機（可能關機）。工作會等最多 10 分鐘，之後失敗。」
    - `state_reasons` 有 `media-empty`/`media-needed` → 顯示「印表機缺紙，請補紙」；有 `media-jam` → 顯示「卡紙」。
- API：`GET /jobs/{id}`、`GET /printer`（缺口 API-4 可以讓這件事更準確）

### Epic D：排程列印

#### D-1 建立一次性排程｜M
身為阿翔，我想要設定「明天 07:30 印這份 PDF」，以便早上出門前就印好。
- AC
  - 表單：檔案、名稱（選填，預設用檔名）、日期時間（`<input type="datetime-local">`，iOS 會跳出原生選擇器）和列印選項（沿用 B-2、B-4 的元件）。
  - 時區預設用伺服器的 `DEFAULT_TIMEZONE`，畫面標示「台北時間」；除非開了進階選項，否則不讓使用者改時區。
  - 送出時把值轉成 `run_at=YYYY-MM-DDTHH:mm`。收到 201 後顯示「將於 10/22（三）07:30 列印」（來自 `next_run_at`）。
  - 400（時間已過、檔案無法列印）時，在欄位旁邊顯示錯誤；檔案和選項在建立時就檢查，所以錯誤會當場出現。
- API：`POST /print-schedule`（`kind=once`）

#### D-2 用友善的方式設定週期排程｜M
身為阿翔，我想要用「每週一 09:00」這種選法，而不是寫 cron，以便快速設定。
- AC
  - 頻率選項：每天／每週（可以選多個星期幾）／每月（選日期 1–28），再加上時間。前端轉成 cron，例如「每週一 09:00」轉成 `0 9 * * 1`。
  - 「進階：自訂 cron」（C）可以直接輸入 cron，旁邊即時顯示中文說明。
  - 建立後顯示「下次列印：10/27（一）09:00」（`next_run_at`）。
- API：`POST /print-schedule`（`kind=cron`）

#### D-3 噴頭保養範本｜S
身為阿翔，我想要一鍵建立「每週一印噴頭檢查頁」，以便不用自己準備檔案，墨水也不會乾掉。
- AC
  - 排程頁有「建立噴頭保養排程」的卡片。前端內建一份四色（C/M/Y/K）色塊測試頁 PDF，按下後直接用 `kind=cron`、`cron=0 9 * * 1`、`name=噴頭保養`、`quality=normal`、A4 建立，使用者只需要確認星期幾和時間。
  - 如果已經有同名的排程，改成顯示「已設定（下次：…）」。
- API：`POST /print-schedule`（測試頁是前端的靜態檔）

#### D-4 排程列表和狀態｜M
身為阿翔，我想要看到所有排程的下次執行時間和上次結果，以便確認保養頁每週都有印。
- AC
  - 每張卡片顯示：名稱、中文的時間描述（cron 轉成「每週一 09:00」）、下次執行時間、啟用開關、上次執行時間和結果。
  - `last_status` 對照：`submitted` 已送出、`failed` 失敗（附上 `last_error`）、`missed` 錯過（服務停機超過 1 小時）。

  - 已執行過的一次性排程顯示「已完成」，並且不顯示啟用開關。
- API：`GET /print-schedule`、`GET /print-schedule/{id}`、`GET /jobs/{id}`

#### D-5 暫停／恢復排程｜M
身為阿翔，我想要出國時暫停保養排程，回國再恢復，以便不浪費墨水。
- AC
  - 開關切換時送出 `{"enabled": false|true}`，並採用樂觀更新；失敗時還原開關並顯示 toast。
  - 恢復後依回應更新「下次執行」（從現在開始重新計算，暫停期間錯過的不會補印）。
  - 409（一次性排程已過期）時顯示「這個單次排程的時間已過，無法恢復」。
- API：`PATCH /print-schedule/{id}`

#### D-6 立即執行、改名、刪除｜S
身為阿翔，我想要馬上印一次排程的文件、改名字或刪掉排程，以便管理排程。
- AC
  - 「立即列印」：成功後 toast 顯示「已送出」，並連到該工作；原本的時間表不變。400 時顯示 `last_error`。

- API：`POST /print-schedule/{id}/run`、`PATCH /print-schedule/{id}`、`DELETE /print-schedule/{id}`

## 5. 非功能需求

### 5.1 手機可用性（iPhone Safari 優先）
- **觸控**：可點擊區域至少 44×44pt；主要動作（列印、開始掃描）放在拇指搆得到的下半部，或做成底部固定按鈕。
- **版面**：`<meta name="viewport" content="width=device-width, initial-scale=1, viewport-fit=cover">`；底部導覽列和固定按鈕要加上 `env(safe-area-inset-bottom)`；寬 375px 時不能有水平捲軸；用 `100dvh` 而不是 `100vh`。
- **輸入**：所有輸入框的 `font-size ≥ 16px`（避免自動放大）；數字欄位用 `inputmode="numeric"`；頁碼欄位用 `inputmode="text"`（要能輸入 `-` 和 `,`）；日期時間用原生的 `datetime-local`。
- **加到主畫面**：提供 `manifest.webmanifest`、`apple-touch-icon` 和 `display: standalone`；standalone 模式下仍要能登入並保持 session。
- **背景與網路**：iOS 會暫停背景分頁的計時器，所以所有輪詢在 `visibilitychange` 回到前景時要立刻重新抓一次；`navigator.onLine` 為 false 時顯示「網路已中斷」橫幅。
- **輪詢頻率**：工作和掃描進度每 2 秒；掃描器忙碌和送紙器狀態每 3 秒；首頁印表機狀態每 15 秒；只在頁面可見時輪詢（`GET /printer` 和 `GET /scanner` 每次都會打到實體機器）。
- **語言與時間**：介面用繁體中文；時間一律用 `DEFAULT_TIMEZONE`（Asia/Taipei）顯示，格式如「10/22（三）07:30」；API 回傳的 ISO 時間已經帶時差，`created_at` 則是 epoch 秒。
- **無障礙與主題**：狀態不能只靠顏色，要同時有文字；支援深色模式（`prefers-color-scheme`）；Toast 不要遮住底部導覽列。
- **效能**：首次載入在 4G 下 3 秒內可以操作（JS gzip 後 < 200KB 是目標）；pdf.js 這類大型套件要延遲載入。

### 5.2 安全（外網暴露）
- **只走 HTTPS**：透過反向代理（例如 Caddy 或 Cloudflare Tunnel）終結 TLS，並加上 HSTS；HTTP 一律轉址。
- **通行碼強度與暴力破解**：6 個字母、不分大小寫，只有約 3 億種組合，**一定要限流**。建議同一個 IP 15 分鐘內錯 5 次就鎖定，另外加上全域上限，例如每分鐘 30 次錯誤；比對要用常數時間；log 不能記錄輸入的通行碼。
- **Session**：cookie 設 `HttpOnly; Secure; SameSite=Strict; Path=/`，有效期 `SESSION_DAYS`。通行碼不能出現在網址、`localStorage` 或前端程式碼裡。更換 `ACCESS_CODE` 時，所有舊 session 都要失效（例如用通行碼衍生簽章金鑰）。
- **CSRF**：`SameSite=Strict` 再加上所有寫入操作只接受 `multipart/form-data` 或 JSON，並檢查 `Origin` 標頭。
- **涵蓋範圍**：所有 API（包括 `/docs`、`/openapi.json`、`/scans/{id}/file`）都要驗證；掃描檔可能是證件，下載回應加上 `Cache-Control: private, no-store`。
- **其他**：加上 `X-Robots-Tag: noindex` 和 `robots.txt` 禁止索引；反向代理的上傳上限要和 `MAX_UPLOAD_MB`（100MB）一致；前端顯示錯誤時不能把內部 IP 或主機名稱（例如 `cannot talk to scanner: ...192.168.x.x`）直接給使用者看，要收在「詳細資訊」裡，或在後端過濾。

### 5.3 錯誤狀態對照（前端集中成一個 mapping）

| 情況 | 偵測方式 | UI 文案（範例） | 使用者可以做的事 |
|---|---|---|---|
| 印表機離線或關機 | `GET /printer` 回 502；工作卡在 `queued` | 「無法連線到印表機，請確認電源和 Wi‑Fi。工作會等最多 10 分鐘。」 | 重新整理、取消工作 |
| 缺紙 | `state_reasons` 有 `media-empty`、`media-needed` | 「印表機缺紙，補紙後會自動繼續。」 | 補紙 |
| 卡紙 | `media-jam` | 「印表機卡紙，請排除後再試。」 | — |
| 蓋子沒關 | `door-open`、`cover-open` | 「印表機蓋子未關好。」 | — |
| 墨水偏低或用完 | `marker-supply-low`、`marker-supply-empty`、`level ≤ 15` | 「黑色墨水偏低」／「黑色墨水已用完」 | — |
| 掃描器忙碌 | `GET /scanner` 的 `busy=true`；`POST /scan` 回 409 `scanner is busy…` | 「掃描器使用中，請稍候。」（按鈕自動恢復） | 等待 |
| 掃描器不是待機 | 409 `scanner is <state>` | 「掃描器正在處理其他工作，請稍後再試。」 | 重試 |
| 送紙器沒紙 | `adf_state != ScannerAdfLoaded`；409 `the document feeder is empty` | 「送紙器沒有紙，請放入文件。」 | 放紙後自動啟用 |
| 掃描失敗 | `GET /scans/{id}` 的 `status=failed` | 「掃描失敗」＋詳細資訊 | 重試、刪除紀錄 |
| 掃描檔已過期 | 410 | 「這個檔案已超過保存期限，已被刪除。」 | 重新掃描 |
| 掃描尚未完成就下載或刪除 | 409 | 「掃描還在進行中。」 | 等待 |
| 檔案太大 | 413 | 「檔案超過 100 MB。」 | 換檔 |
| 格式不支援 | `POST /print` 400 | 「這個檔案格式無法列印。」 | 換檔 |
| 參數錯誤 | 422 | 「設定有誤，請檢查欄位。」（標出欄位） | 修正 |
| 排程時間已過或 cron 錯誤 | `POST /print-schedule` 400 | 「時間必須晚於現在。」／「重複設定無效。」 | 修正 |
| 一次性排程無法恢復 | `PATCH` 409 | 「這個單次排程的時間已過，無法恢復。」 | 刪除或重建 |
| 工作紀錄不見 | `GET /jobs/{id}` 404 | 「找不到這個工作（服務可能重新啟動過）。」 | — |
| 登入過期 | 任何 API 回 401 | 導到登入頁 | 重新登入 |
| 嘗試太多次 | 429 | 「嘗試次數過多，請 N 分鐘後再試。」 | 等待 |
| 手機斷網 | `navigator.onLine=false`、fetch 拋出 TypeError | 「網路已中斷。」橫幅 | 連線恢復後自動重試讀取（寫入操作不自動重送） |
